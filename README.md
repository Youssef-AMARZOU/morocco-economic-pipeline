# Morocco Economic Pipeline

End-to-end R/Python ETL pipeline for Morocco macroeconomic analysis.

## Kaggle
- **Kernel**: [amarzouyoussef/maroc-pipeline-r](https://www.kaggle.com/code/amarzouyoussef/maroc-pipeline-r)
- **Dataset**: [amarzouyoussef/economie-maroc-rasd](https://www.kaggle.com/datasets/amarzouyoussef/economie-maroc-rasd)
- **Models**: [morocco-economic-forecasting](https://www.kaggle.com/models/amarzouyoussef/morocco-economic-forecasting)

## Components
- ETL: fetch_wb, fetch_owid, fetch_imf, clean, merge, spark_etl
- Analysis: R pipeline with ML/DL, ARIMA, scenarios, benchmarking
- Models: Random Forest, Lasso, ARIMA, Deep Learning (Keras)
- Report: HTML report with TOC, executive summary, recommendations

## Data Sources
- World Bank (WDI)
- IMF (WEO)
- UNDP (HDI)
- Our World in Data (OWID)
- Casablanca Stock Exchange
